Primeros pasos para clientes

Guía para comenzar con una aplicación de KepaTecnologia sin conocimientos técnicos. No introduzcas datos reales hasta confirmar que tu acceso y la aplicación están preparados.

1. Comprueba tu acceso

Solicita al responsable la dirección oficial de la aplicación, las credenciales de prueba cuando proceda y los requisitos del dispositivo. No compartas contraseñas por mensajería.

2. Haz una prueba sencilla

Con datos ficticios, realiza una tarea habitual: crear un borrador, consultar un registro o probar un flujo autorizado. Anota qué esperabas y qué ocurrió.

3. Si aparece un error

No repitas acciones de cobro, envío o borrado. Guarda la hora, pantalla, pasos para reproducirlo y mensaje de error, evitando datos sensibles.

4. Comprueba tu preparación

5. Practica con una guía específica

Consulta los pasos de comprobación para Llamadas360 y Electricista360, con advertencias sobre funciones todavía pendientes de validar.

6. Antes de empezar a trabajar

Confirma con el responsable que la prueba ha terminado, que tienes los permisos adecuados y que las funciones necesarias están verificadas. Si algo falla, detén esa operación y solicita revisión; no uses información real para investigar el problema.
